## How to Deploy (Step by Step)

### Prerequisites
- Git installed
- Node.js installed (any recent version — the build script uses zero dependencies)
- Access to the ScreenStacka GitHub repo

### Steps

1. **Clone the repo** (or navigate to your local copy):
   ```bash
   git clone https://github.com/planetofthepaul/ScreenStacka.git
   cd ScreenStacka
   ```

2. **Back up the current site:**
   ```bash
   cp index.html index.html.backup
   ```

3. **Copy all new files into the repo root.** From the zip file you downloaded, copy:
   - `index.html` (replaces existing — has new footer, disclosure, Popular Comparisons section)
   - `build.js` (new)
   - `about/` directory (new)
   - `contact/` directory (new)
   - `privacy/` directory (new)
   - `terms/` directory (new)
   - `compare/` directory (new — contains 36 subdirectories)

4. **Verify the build script works locally:**
   ```bash
   node build.js
   # Should output: ✅ Built 36 comparison pages in ./compare/
   ```

5. **Test locally** (optional but recommended):
   ```bash
   # Python 3
   python3 -m http.server 8000
   # Then open http://localhost:8000
   ```
   Check:
   - Homepage loads, new footer visible, Popular Comparisons grid links work
   - Click into `/compare/55-vs-65/` — visual overlay renders, content looks right
   - Footer links work on all pages (About, Contact, Privacy, Terms)
   - Mobile: resize browser to confirm responsive layout

6. **Commit and push:**
   ```bash
   git add .
   git commit -m "Add 36 comparison pages, about, contact, privacy, terms, updated homepage"
   git push origin main
   ```

7. **GitHub Pages will auto-deploy.** If the repo is already configured for GitHub Pages (which it is — the current site is live), the new pages will be live within a few minutes at their URLs.

8. **Verify live:**
   - https://screenstacka.com/ (updated homepage)
   - https://screenstacka.com/compare/55-vs-65/ (flagship comparison)
   - https://screenstacka.com/about/
   - https://screenstacka.com/privacy/
   - https://screenstacka.com/terms/
   - https://screenstacka.com/contact/

## How to Make Changes

### Change the footer across all pages
The footer exists in two places:

1. **`build.js`** (for all 36 comparison pages) — search for `<footer>` in the template string, edit it, then run `node build.js` to regenerate all pages.
2. **Manually maintained pages** (`index.html`, `about/index.html`, `contact/index.html`, `privacy/index.html`, `terms/index.html`) — edit the `<footer>` section in each file. There are 5 of these.

After editing, commit and push.

### Change comparison page content
Edit the relevant function in `build.js`:

- **Content/copy**: `writeComparisonParagraphs()` function
- **Viewing distance logic**: `getViewingDistance()` function
- **Room recommendations**: `getRoomRec()` function
- **Use case bullets**: `getUseCases()` function
- **Amazon links**: `AMAZON_LINKS` object
- **Which sizes to generate**: `SIZES` array and `PRIORITY_COMBOS` array
- **Page layout/design**: the HTML template string inside `generateComparisonPage()`
- **Schema.org data**: the `schema` object inside `generateComparisonPage()`

After editing, run `node build.js` to regenerate, then commit and push.

### Add a new TV size
1. Add the size to the `SIZES` array in `build.js`
2. Add the new size combos to `PRIORITY_COMBOS`
3. Add an Amazon link in `AMAZON_LINKS`
4. Run `node build.js`
5. Optionally add the new comparison to the Popular Comparisons grid on `index.html`
6. Commit and push

### Change the email address
Search-and-replace `transactional99@proton.me` across:
- `about/index.html`
- `contact/index.html`
- `privacy/index.html`
- `terms/index.html`

### Change the Plausible Analytics snippet
Search-and-replace the script tag across all files. It appears in `build.js` (for comparison pages) and in each of the 5 manually maintained pages.

## Math Reference

All dimensions assume a 16:9 aspect ratio (standard for modern TVs).

**Formulas:**
```
width  = diagonal × 16 / √(16² + 9²) = diagonal × 16 / √337
height = diagonal × 9 / √(16² + 9²)  = diagonal × 9 / √337
area   = width × height
```
